HƯỚNG DẪN NỘP BÀI TẬP LỚN
=========================

1. BÁO CÁO (FILE WORD)
----------------------
- Mở file `FINAL_REPORT.md` trong thư mục này.
- Copy toàn bộ nội dung.
- Dán vào Microsoft Word.
- Định dạng lại theo quy định của trường (Font Times New Roman, Size 13, v.v...).
- Điền thông tin cá nhân (Họ tên, MSSV, Lớp) vào trang bìa.
- Lưu file thành: `BaoCao_DoAnCaNhan_[HoTen]_[MSSV].docx`

2. SOURCE CODE (MÃ NGUỒN)
-------------------------
- Nén toàn bộ thư mục `teddy_bear_shop` thành file .zip hoặc .rar.
- Đặt tên file: `SourceCode_DoAnCaNhan_[HoTen]_[MSSV].zip`
- Lưu ý: Không cần nộp thư mục `node_modules` (nếu có) để giảm dung lượng, nhưng dự án này dùng PHP thuần nên không vấn đề gì.
- Đảm bảo file `teddy_bear_shop.sql` đã có trong thư mục để giảng viên import CSDL.

3. NỘI DUNG CẦN GỬI
-------------------
Gửi email cho GV với tiêu đề:
"[Môn học] - [Họ tên] - [MSSV] - Báo cáo đồ án cá nhân"

Đính kèm:
1. File Báo cáo (Word/PDF).
2. File Source Code (.zip).
